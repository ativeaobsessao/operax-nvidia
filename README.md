# OPERAX NVIDIA LP

Landing page mobile-first React/Vite para a Mega Operação NVIDIA.

## Stack
- React 18 + Vite 6 + TypeScript
- Node 26.x
- Inter Variable self-hosted

## Build
```bash
npm install
npm run build
```

## Deploy
Root Directory: `./`
Build Command: `npm run build`
Output Directory: `dist`
